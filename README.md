# Minecraft-Terminal-Launcher
Language: **English** · [简体中文](./README.zh-CN.md)

# Introduction
A lightweight, open-source, cross-platform Minecraft launcher that runs entirely in your terminal with minimal resource usage. All features except premium account login and game launching work perfectly in a pure terminal environment.

# Requirements (Run from Source)

- Python >= 3.8
- All dependencies listed in `requirements.txt`

# Requirements (Run Packaged Executable)

- Windows >= 10 / Linux (matching architecture)
